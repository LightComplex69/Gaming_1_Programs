# Gaming 1 Programs
A compilation of programs from my first coding class.
## Background
Most of these applications were homework assignments or projects assigned to us in a Game Design class I took in high school. The class focused on programming fundamentals such as variables, functions, classes, loops, and lists. It then took these fundamentals and slowly introduced ways to utilize them within a game design context, which can be seen in some of the more interactive programs.  

*Disclaimer: Given that these programs were made very early in my coding career, some programs have been modified recently to ensure proper functionality.*
