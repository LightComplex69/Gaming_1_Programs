# Gaming 1 Programs
A compilation of programs from my first coding class.
## List of Programs
- **Bigger Number**
  * Contains a function that, when given two numbers, will return the bigger number of the two. These numbers are printed to the window and Console for debugging.
- **Border Patrol**
  * A circle starts at the upper left corner and moves 
  right along the edges of the window in a clockwise manner.  
  The circle stays on the screen at all times and the movement repeats. 
  The circle should be 100×100 px and should be 50 px from the edge of 
  the window.
- **Bouncer**
  * A yellow circle moves around a blue screen diagonally.
 The circle has your first name initial inside of it in black text.
 When the circle touches any edge of the screen it will bounce off of
 the edge to stay in the screen.  When you press the space bar the circle
 will also bounce anywhere on the screen.  When the mouse is pressed the
 color of the window will toggle between blue and green.
## Background
This project was something that I had been working on throughout high school. I have always been interested in developing fighting games, so I used to project to explore various aspects of arcade style 2D fighting games. I experimented with things like extracting sprites from sprite sheets, pulling character and move properties from a JSON file, and basic movement.
